# Studio Icons

Silhouette-style SVG icons for film and TV studios, designed for rendering at 80px on dark backgrounds. Follows a unified stroke-based style guide.

## Style Spec

- **viewBox**: 0 0 24 24
- **Stroke**: 1.5px, `round` linecap/linejoin
- **Fill**: `none` (outline-first silhouette)
- **Base color**: `currentColor` → `#FFFFFFE6` on dark cards
- **Accent wash**: Single brand color overlay at 0.10-0.18 opacity
- **Target span**: 16-20 units on the 24-unit grid

## Usage

Look up by normalized studio name (lowercase, trimmed). The catalog maps each studio to its SVG file in `icons/`.

## Coverage

70+ studios and growing. See `catalog.json` for the full list.
